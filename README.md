# Site TECHMALI

Ce dossier contient une version responsive du site vitrine TECHMALI.

## Publication avec GitHub Pages
1. Créez un dépôt GitHub distinct, par exemple `techmali.tech`.
2. Téléversez `index.html` et `CNAME` à la racine de la branche `main`.
3. Dans Settings > Pages, choisissez le déploiement depuis `main` et le dossier `/ (root)`.
4. Dans le champ Custom domain, indiquez `techmali.tech`, puis attendez la validation DNS.
5. Chez Namecheap, configurez les quatre enregistrements A GitHub Pages indiqués dans la documentation GitHub, et un CNAME `www` vers `mrnabotraderexpert-wq.github.io` si vous souhaitez aussi `www.techmali.tech`.

Conservez l'enregistrement DNS `sugu` qui pointe vers le site SUGU. Ne supprimez pas les enregistrements existants sans vérifier leur usage.

Le site présente TECHMALI comme une initiative en cours de développement et ne prétend pas qu'une entreprise individuelle est déjà immatriculée.
